# Етикетки для спецій

[English](README.md) · **Українська**

<p align="center"><img src="images/web/standing.jpg" alt="П'ять квадратних баночок зі спеціями з надрукованими етикетками" width="100%"></p>

Однакові етикетки для маленьких квадратних баночок зі спеціями, які можна надрукувати вдома. Кожну спецію описуєш у TOML-файлі; одна команда розкладає все на аркуші A4 як двосторонній PDF з лініями відрізу, QR-кодами та розміткою для скотчу на звороті. Надрукував, заламінував прозорим скотчем, наклеїв двосторонній, вирізав.

## Що отримуєш

Кожен запис у `spices.toml` перетворюється на до трьох етикеток:

| етикетка | розмір     | куди                        | вміст                                     | коли            |
|----------|------------|-----------------------------|-------------------------------------------|-----------------|
| передня  | 28 × 22 мм | бік баночки, верхня третина | назва, підзаголовок, примітка, походження | завжди          |
| задня    | 28 × 30 мм | протилежний бік             | назва і таблиця пропорцій                 | є `contents`    |
| нижня    | ⌀ 25 мм    | заглиблення на дні          | QR-код, назва надрукована ззаду           | є `url`         |

Баночка на фото — скляна, квадратна, 30 мм, висотою 70 мм, із заглибленням ⌀ 27 мм на дні. Передня етикетка навмисно коротка, щоб було видно вміст. Кожен розмір — одне число в блоці стилів, тож для інших баночок достатньо змінити один рядок.

## Як це працює

```
spices.toml     що друкувати — один блок [[spice]] на баночку
labels.typ      як виглядає — геометрія, шрифти, розміри в блоці STYLE; нижче — код розкладки
build.sh        одна команда: spices.toml → labels.pdf (і PNG-прев'ю)
atb_spices.md   приклад: шість спецій з АТБ з посиланнями
```

Рушій — [Typst](https://typst.app). Він читає TOML напряму, розкладає в точних міліметрах, вимірює текст, щоб автоматично зменшувати довгі назви, і малює QR-коди пакетом [tiaoma](https://typst.app/universe/package/tiaoma). Без Python, LaTeX чи браузера.

## Швидкий старт

Потрібен Typst 0.14 або новіший у PATH, або Nix (скрипт сам підтягне Typst через `nix shell`, якщо його немає).

```sh
./build.sh                 # усі етикетки → labels.pdf
./build.sh паприка імбир   # лише записи, у назві яких є ці слова
PNG=1 ./build.sh           # додатково прев'ю preview/page-N.png
```

## Опис спеції

```toml
[[spice]]
name     = "Суміш перців"              # обов'язково; зменшується, потім переноситься на два рядки
subtitle = "мелена"                    # дрібний курсив під назвою
contents = { "перець чорний" = "49 %", "перець духмяний" = "15 %" }   # таблиця пропорцій, порядок зберігається
source   = "АТБ · Своя Лінія"          # походження або магазин
note     = "обсмажити, змолоти"        # один короткий рядок над source
url      = "https://..."               # куди веде QR — чим коротше, тим краще
copies   = 2                           # скільки однакових комплектів друкувати
```

Значення в `contents` друкуються як є: числа для частин (`2`, `0.5`), рядки для решти (`"49 %"`, `"дрібка"`, `""` для списку інгредієнтів без кількостей).

## Друк і збирання

1. Друкуй `labels.pdf` двосторонньо з перегортанням по довгому краю, у масштабі 100 % / «фактичний розмір». Ніколи «за розміром сторінки». Лінійка 50 мм у нижньому колонтитулі має бути рівно 50 мм.
2. Непарні сторінки — лицьовий бік аркуша. Кожна парна — зворот попереднього аркуша: ті самі контури дзеркально, плюс назва спеції за кожним QR-кружечком.
3. Заламінуй лицьовий бік прозорим скотчем смуга за смугою з нахлестом 1–2 мм, притискаючи ребром картки. Етикетки йдуть впритул, тож деякі стики ляжуть на етикетку — добре пригладь їх.
4. Наклей двосторонній скотч на зворот усередині надрукованих контурів. На порожній папір нічого не витрачається.
5. Ріж з лицьового боку по сірих лініях. Сусідні етикетки мають спільну лінію, тож один розріз розділяє дві. Різати крізь обидва скотчі — тоді папір, ламінат і підкладка запечатуються одним краєм. Кружечки можна вирізати приблизно: заглиблення ховає край.

Етикетка з червоною рамкою не вмістила текст. Скороти його або збільш висоту цієї етикетки в блоці стилів.

## Налаштування

Усе візуальне — у блоці `STYLE` на початку `labels.typ`:

- розміри етикеток і проміжок між ними (`gutter`, типово 0; 3–4 мм, якщо хочеш місце для ножиць)
- шрифти: Roboto Condensed із DejaVu Sans як запасним, тож латиниця і кирилиця працюють; якщо Typst не бачить системних шрифтів, задай `TYPST_FONT_PATHS`
- діапазон розміру назви для автопідбору, розміри таблиці й підписів
- розмір QR (16 мм; тримай посилання короткими, щоб код лишався крупним і читався)

Принтери зміщують два боки двостороннього друку до міліметра. Контури на звороті — орієнтир для скотчу, а не для різання: ріж завжди з лицьового боку.
